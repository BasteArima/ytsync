Добавить плейлист

Папка создастся сразу вместе с пустым archive.txt. Укажешь существующую — её архив подхватится, и уже скачанное не пойдёт заново.

Загрузка

Качество максимальное: пустое поле формата означает лучшее видео плюс лучший звук. Склейка идёт в mkv без перекодирования, процессор не нагружается.

Вид

Масштаб хранится в браузере, на каждом устройстве свой — на сервер не отправляется.

Доступ

Вход запоминается в этом браузере на полгода. Сброс сессий разлогинит все устройства, включая это.

…

Нужны только для приватных плейлистов и видео 18+. Для обычных ссылок не требуются. Формат — Netscape cookies.txt. Всё, что не относится к YouTube и Google, отбрасывается при загрузке. Файл лежит с правами 600 и обратно не читается.

Вставить текстом

Через буфер табуляции часто ломаются — если ругнётся на формат, грузи файлом.

Сверка файлов без ID

У части файлов в имени нет ID видео, поэтому сопоставить их автоматически нельзя — для YouTube нет базы хешей. Здесь подбираются похожие по названию, решение за тобой. Подтверждённые ID дописываются в archive.txt, и эти видео больше не скачаются.
